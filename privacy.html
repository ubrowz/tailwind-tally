Tailwind Tally

Privacy Policy

Effective September 19, 2026 · applies to the Tailwind Tally web app and the Tailwind Tally iOS app, which shows the same web app in a native shell.

The short version

Tailwind Tally doesn't have accounts, doesn't set its own tracking cookies, and doesn't store anything server-side beyond map tiles and Strava data it briefly relays on your behalf. Your GPX route data is processed entirely on your own device. The sections below explain exactly what does happen, and why.

Route files (GPX)

Whether you drop a file in the browser, share one from another app on your phone, or load one from Strava, the route data is parsed and analyzed entirely on your device — in your browser's own JavaScript, or inside the iOS app. It is never uploaded to, or stored on, any server we operate.

Connecting to Strava (optional)

If you choose to tap "Connect to Strava," you're sent to Strava's own login page to authorize Tailwind Tally to read your routes. We request the read and read_all scopes, which let the app list and export your Strava routes (including private ones).

What we receive and how it's used:

  • An access token, scoped by Strava to your account and to the permissions you approved. It's held in your browser's memory for the current page session only, and is discarded when you reload or close the app. It is never written to a database, a file, or browser storage (no localStorage, no cookies set by us).
  • Your Strava name and athlete id, shown in the app so you can see which account is connected (e.g. "Connected as …"). This is displayed, not stored.
  • Your route list and the GPX content of a route you choose to load, used only to render the map and calculations you asked for.

A small backend service we operate (see "Infrastructure," below) performs two things that require holding our Strava application's client secret, which can't safely live in a browser or a mobile app: exchanging Strava's one-time login code for that access token, and relaying the route-list/route-export API calls (only because Strava's API doesn't allow browsers to call it directly - not because it needs our secret). That backend does not log, store, or retain any Strava data that passes through it.

Disconnecting is as simple as reloading the page or restarting the app - there is nothing stored to delete.

Map tiles

Map imagery is served by MapTiler, requested through our backend so our MapTiler API key stays private. MapTiler receives the map area you're viewing and your IP address, the same as any map tile request - no Tailwind Tally-specific personal data is attached to these requests.

Analytics

We use GoatCounter to count page visits. It sets no cookies and collects no personally identifying information - see GoatCounter's privacy policy.

Fonts

Page text uses fonts loaded directly from Google Fonts. Google may log standard web request data (such as your IP address) for these requests, as with any font served from their CDN.

The iOS app specifically

The iOS app is a thin native shell around the same web app described above, so everything on this page applies to it too. The one native-only feature is that Tailwind Tally can be offered as an "Open in…" destination for .gpx files shared from other apps (Strava's own app, Mail, Files, AirDrop). That file is read on-device and handed to the same in-app web page - it is not uploaded anywhere by the app itself.

What we don't do

  • No user accounts, passwords, or sign-up of any kind on our side.
  • No advertising, ad tracking, or ad-network SDKs.
  • No selling or sharing of your data with third parties beyond what's described above (each of which only ever sees a request you directly triggered).
  • No server-side database - the backend that supports this app is intentionally stateless.
